# 🐧 Linux Desktop on Android

Run a Linux desktop environment on your Android phone without root.

This guide uses three main applications:

- 📱 TuxSpan
- 💻 Termux
- 🖥️ Termux:X11

# 📱 Requirements

- Android 8.0 or newer
- Termux
- Termux:X11
- TuxSpan
- Sufficient free storage
- Recommended: 4 GB+ RAM
